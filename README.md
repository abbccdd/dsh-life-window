# 鲸鲸生活窗

一个面向 DeepSeek Harness Web profile 的生活小窗。可纳入多间养鱼会话，把它们的运行状态、养鱼活动和生活资料合并展示；每条记录注明来源。记录可按活动、视频、日记、信件和资料筛选。视频墙按 BV 号合并推荐，保留不同来源的原始理由。

首次接入时已有的日记、信件和视频视为已读；之后新发现的记录显示未读数量。展开内容、打开视频或手动标记后变为已读，也可以按分类全部标记。未读状态存储在当前浏览器；更换浏览器或清除浏览器数据会重新建立基线。相同 BV 的视频只计一次，新增来源不会再次计为未读。长内容在原位置展开和收起。

使用「搜索历史记录」搜索当前分类的标题、正文、视频号和来源；「全部」同时搜索视频。搜索会额外读取更多可访问历史，不包含私密段落或自动发现规则以外的文件。单文件读取长度、候选文件及日报数量仍有限，较久或超限记录可能找不到。每个分类和搜索结果默认显示前 50 条，点击「显示更多」每次再显示 50 条。

## 使用

重启并刷新 DSH 后，右下角点击「鲸鲸生活窗」。窗口会自动检查当前 DSH 宿主的会话，合并显示识别为养鱼活动的会话，不需要逐个选择。展开「自动识别养鱼会话」可以看到识别依据；如出现误判，可排除或恢复。

识别依据包括特定养鱼插件的专用会话或工作目录、运行 `bili.mjs` 养鱼命令、读取或写入明确的养鱼日记或报告文件，以及养鱼日记或挑选工具。普通 B 站搜索、视频查询或聊天中提到插件，不能单独证明是养鱼会话。匹配是启发式而非通用协议，可能误判，也可能漏掉没有这些特征的插件；独立进程中不可见的会话无法识别。

为识别未命名的会话，小窗打开时会通过 DSH 只读接口检查当前宿主会话中的工具调用；首次最多向前检查三页，每页 40 条消息范围。会话用于识别和展示运行状态，不把普通对话或工具执行痕迹充当生活动态。识别结果只保存会话 ID 与依据，不保存发现过程中读取的消息。插件主动发布的生活记录若声明所属会话，会标明来源并可打开该会话。

生活窗自动扫描 DSH 数据目录中的常见养鱼文件结构：明确给用户的 `owner` 日记、混合日记中标明「给主人」的段落，以及带日期且按 BV 号分节的 `out` / `report` 日报。默认 DSH 数据目录还会检查传统的 `~/.bili-ai/out/日期.md`。不需要选择会话或文件；不会自动展示鱼写给自己、不发或无明确归属的私人日记。自动扫描有数量和层级上限，结构不明显的来源可能遗漏。

在「数据来源与连接状态 → 发现更多生活资料」中，也可以手动选择候选文件查看原文；最多添加五个，随时可以移除。资料按文件修改时间显示，文件没有声明会话归属时不会猜测属于哪条鱼。

B 站专门适配器是**可选**的 `dsh-bili-whale`，没有安装时小窗仍可显示任意可访问的 DSH 会话状态、用户选择的资料以及支持开放格式的其他插件事件；缺少的来源在「数据来源与连接状态」中列出。历史日志不能证明实时登录或调度状态。

## 安装

需要 DSH Web profile。完整目录中已包含构建好的客户端：可在 DSH 的「插件 → 添加插件」中选择或输入此目录的绝对路径，安装后重启 DSH 并刷新页面。也可以在终端运行（需要 Node.js 和可用的 DSH CLI）：

```sh
node tools/install.mjs
```

安装器使用本机已有的 DSH CLI，以本地链接安装到 `web` profile，并将配置备份到该 profile 的 `backups/dsh-life-window/`。安装后重启 DSH 并刷新页面。安装位置由 `DSH_HOME` 或系统用户目录自动决定；如 CLI 不在 PATH 中，可设置 `DSH_CLI_JS` 为已安装 DSH 的 `lib/bin.js` 路径。

发布给其他用户时可以分享 `dist/dsh-life-window-0.6.2.tgz`，其中不包含本机安装备份或用户数据。对方可用 `dsh plugin --profile web add "file:<压缩包绝对路径>"` 安装，重启 DSH 并刷新页面。

状态卡片使用用户提供的 Q 版形象图，用户已确认使用授权。

请保留整个项目目录：本地链接会直接使用它。当前版本验证目标为浏览器版 DSH；其他版本或 Desktop 的兼容性需要实测。

卸载时运行 `dsh plugin --profile web remove dsh-life-window`，然后重启 DSH 或刷新页面。不要用备份覆盖整个 profile，否则可能撤销之后的其他更改。

## 数据与边界

- 会话目录和运行状态通过 DSH 的 sessions 服务读取。首次识别最多检查三页、每页 40 条消息范围。每次最多同时读取三个会话，窗口收起时停止请求；无法读取时显示检查失败。独立 headless 进程若不在当前宿主目录中则无法发现。
- 历史接口会返回最近会话消息和工具调用；只提取工具名称、文件操作的路径以及 shell 调用的命令字段进行本地识别。不展示普通对话、reasoning、工具参数或工具输出；不会发送给模型或第三方。识别结果、排除的会话 ID 和所选资料 ID 存在该浏览器的 localStorage；不自动发送消息，也不会改变各会话的模型上下文或记忆。用户手动添加的资料根据名称判断日记或信件，无法判断时归入资料。
- `dsh-bili-whale` 适配器只读 DSH home 的 `bili-whale.config.json`、`whale-night.json`、`whale-diary.md`、`whale-outbox.md`、`whale-round.log`。尊重 `DSH_HOME` 和 `BILI_WHALE_CONFIG`。不读取 cookie。
- 日记仅提取明确标为「给主人」等的段落；不读取独立的私人日记文件，也不展示「给自己」「想说（不发）」段落。未识别的日记格式不会自动展示。
- 作息来自持久计划或配置窗口，本身无法证明调度器在线。如果 Windows 上该插件关闭生物钟的原因明确写有「计划任务 任务名」，生活窗会只读查询该任务的状态和下次运行时间；无法读取或名称不唯一时显示待确认。其他调度方式不会被猜测，没有计划时不会编造下次唤醒。文件来源和缺失、解析错误可在小窗中查看。
- 日记仅带日期时显示日期，不伪造具体发生时间。活动栏从成功结束的 B 站任务日志中提取明确标为「最值得看」等且带 BV 号的推荐行，显示视频及理由，不展示整段日志；格式不匹配时不会编造内容。其他插件可通过下述开放格式提供活动。
- 自动发现每次最多处理 30 个匹配文件，以及默认目录下最多 20 个传统日报；搜索时分别扩大到 100 个，混合日记最多提取 500 节。日记源最多读取末尾 256 KiB，自动发现文件最多读取末尾 128 KiB；传统日报超过 128 KiB 会跳过。日报只提取带 BV 的标题分节中明确标记的标题和推荐理由，不读取其他字段作为推荐。视频墙按 BV 合并来源，不联网获取封面或标题。日期取文件名日期，不伪造具体时间。格式不同、文件过大或来源在非默认目录时可能遗漏；可在数据来源中查看已识别文件。
- 生活记录接口检查实际连接地址，只接受本机回环连接和同源访问；带转发来源请求头的代理请求会被拒绝。若通过代理暴露 DSH，代理必须保留转发来源信息或在代理自身限制访问。小窗不主动向外发送记录或执行 B 站操作。
- 通用候选发现只返回文件名、大小和修改时间；排除常见密钥、配置、私人、会话、备份及缓存路径，不跟随符号链接。用户主动添加后读取至多 128 KiB 的文件尾部，并在页面显示至多 12,000 字符；仅按原文展示，不自动把内容理解为日记、分享或消息。

## 给其他插件作者：可选生活来源格式

这是本项目提出的开放约定，**不是现有 DSH 官方标准**。生产者可将准备公开给生活窗展示的内容写入 `DSH_HOME/life-window/providers/<英文文件名>.json`：

```json
{
  "version": 1,
  "providerId": "my-fish",
  "name": "我的鱼",
  "updatedAt": "2026-10-28T10:00:00Z",
  "events": [
    {"id": "event-1", "time": "2026-10-28T09:30:00Z", "kind": "letter", "title": "给你的一句话", "text": "今天遇到一件有趣的事。", "sessionId": "可选的DSH会话ID"}
  ]
}
```

`kind` 支持 `activity`、`diary`、`letter`；时间为 ISO 字符串或毫秒时间戳。提供 `sessionId` 的记录只在该会话已纳入且符合显示范围时显示，不提供则作为未关联的独立来源。来源最多读取 20 个文件、每个 256 KiB，最多展示每个来源前 100 条；格式错误在来源状态中显示。这个协议只交换文字事件，不执行其中的命令或动作。生产者应先写临时文件再原子替换，避免读到半份 JSON。

## 开发和验证

```sh
node tools/build.mjs
node --test tests/*.test.mjs
node tools/server.mjs
```

演示地址 `http://127.0.0.1:3088/dsh-life/demo` 只显示示例数据；`/dsh-life/` 可查看真实文件来源，但单独页面不连接 DSH 当前会话。

`src/session-controller.js` 负责识别会话和汇总状态；`src/model.js` 处理状态、记录分类和视频合并；`src/widget.js` 和 `src/widget.css` 管理展示。`lib/discovery.js` 发现候选资料，`lib/auto-sources.js` 提取公开日记和日报，`lib/providers.js` 读取开放格式，`lib/sources.js` 是原有 B 站适配器；`lib/client.js` 由构建脚本生成。
